# Who's Your Dad?

接住爹地灑下來的小費，但小心那盒適尿通。

線上遊玩：https://aether-tek.github.io/whos-your-dad/

## 檔案結構

```
index.html        遊戲本體（HTML + CSS + JS）
assets/
  background.png  麵包店背景
  boss1~9.png     爹地的九種髮量狀態
  bill1~100.png   七種面額鈔票
  pill.png        適尿通藥盒
  life.png        補命代幣（爹地吐舌照圓形裁切）
  win.mp4         三關全過的慶祝影片
```

## 常見修改

關卡難度全部集中在 `index.html` 的 `LEVELS` 陣列（第 393 行）：

| 參數 | 意義 |
|---|---|
| `time` | 關卡秒數 |
| `target` | 過關所需金額 |
| `pill` | 適尿通出現機率（0~1） |
| `spawn` | 掉落物生成間隔（毫秒，越小越密） |
| `bossMove` | 爹地移動間隔（毫秒，越小越跳） |
| `speedBase` | 基礎落下速度 |
| `drift` | 斜線幅度，0 為垂直 |
| `speedMul` | 速度倍率 |
| `junk` | 是否出現小面額干擾鈔 |

`WIN_AFTER_LEVEL` 控制第幾關過關後播放影片，測試時可改成 `0`（第一關就播）。

## 操作

- 電腦：滑鼠移動、方向鍵或 WASD，錢包可上下左右移動
- 手機：手指拖曳，錢包會停在手指上方一點，不會被手指遮住
- 垂直範圍限制在畫面下半部再往上一點（`BASKET_MIN_Y` ~ `BASKET_MAX_Y`），不能蹲在爹地正下方

## 世界出差模式

開始畫面按「🌍 世界出差」。從九國隨機抽三國、順序隨機，每國一關，每國一個專屬機制。過一國護照蓋一章，集滿六國解鎖成就。國家定義在 `COUNTRIES` 陣列，一趟幾站由 `TRIP_STOPS` 控制。

| 國家 | 機制 `mech` | 內容 |
|---|---|---|
| 🇯🇵 日本 | `disguise` | 六成藥盒偽裝成 ¥50 鈔票，掉到一半（y>300）才露出真面目 |
| 🇲🇽 墨西哥 | `dual` | 每次生成從帽子左右兩側各掉一個 |
| 🇮🇳 印度 | `sine` | 所有掉落物沿中心線做 S 形擺動 |
| 🏴󠁧󠁢󠁳󠁣󠁴󠁿 蘇格蘭 | `wind` | 每 5 秒隨機換風向，所有掉落物被吹偏，畫面上方顯示風向 |
| 🇪🇬 埃及 | `goldrush` | 金鈔 16%、藥盒 36%，目標 1200 |
| 🇧🇷 巴西 | `confetti` | 每秒 22% 機率彩帶遮住畫面 1.3 秒，有干擾小鈔 |
| 🇰🇷 韓國 | `kcombo` | 連擊倍率翻倍，但連擊 ×N（N≥3）斷掉扣 N×10 |
| 🇲🇳 蒙古 | `homing` | 藥盒每幀朝錢包 x 追 1.4px |
| 🇰🇪 肯亞 | `sprint` | 爹地每 110ms 換位、生成間隔 200ms，藥盒較少 |

服裝圖 `assets/country-*.jpg` 由拼貼圖裁切（20 國全切好，目前用 9 國），出現在關卡介紹、護照，以及出差進行中的遊戲背景（蓋一層淡暗色）；頂端發錢的爹地仍用九張髮量圖。

**達標即過關**：故事與出差模式中，分數一達到目標立刻結算過關，不必等時間跑完；時間到仍未達標才算失敗。

## 耐玩元素

- **高空加成**：錢包越高，接到的錢加成越多，最低點 ×1.0、最高點 ×1.5，飄字帶 ↑ 表示有吃到加成
- **加班模式（無盡）**：三關全過後解鎖。沒有目標、沒有時限，每 15 秒一波，藥盒機率、掉落速度、斜線幅度隨秒數爬升，直到藥盒過量倒下或按「下班結算」（Esc）主動結束。參數在 `endlessLv()`
- **排行榜**：故事、加班各存前五名於 localStorage（`wyd_board_story` / `wyd_board_endless`），上榜可留 4 字名字
- **成就**：12 個，定義在 `ACH` 陣列，解鎖狀態存 `wyd_ach`，開始畫面可查看
- **音效**：Web Audio 合成，無外部檔案，左下角可靜音（存 `wyd_muted`）

## 遊戲規則

- 接到 $10 / $50 / $100 加對應分數，乘上連擊倍率與高空加成
- 接到適尿通扣 50 分，爹地髮量 +1（分數可扣成負數）
- 接到 ✂️ 剪刀髮量 −1（道具中 70%）；🪒 刮鬍刀髮量 −2（30%，掉得更快）。道具不加分、不影響連擊
- 髮量整場累積，不因過關或重玩而重置
- **開局三命、上限五命**（`START_LIVES` / `MAX_LIVES`），三關共用，加班模式也用同一組
  - 沒達標：扣一命，該關分數歸零重來，髮量不還
  - 髮量 9/9 再接到適尿通：扣一命急救，髮量洗回 5/9（`RESCUE_HAIR`），該關重來；加班模式則原地繼續
  - 命歸零才真正結束
  - 「爹地人頭代幣」`assets/life.png`（由吐舌照裁切）每次生成 4%（`LIFE_CHANCE`），每關最多 3 個（`LIFE_PER_LEVEL`，加班模式每波重算）。代幣 76px、速度全場最慢（基礎速度的一半）；接到補一命，上限 5；命已滿時改給 $100（`LIFE_FULL_BONUS`）
