# Who's Your Dad?

接住爹地灑下來的小費，但小心那盒適尿通。

線上遊玩：https://aether-tek.github.io/whos-your-dad/

## 檔案結構

```
index.html        遊戲本體（HTML + CSS + JS）
assets/
  background.png  麵包店背景
  boss1~9.png     爹地的九種髮量狀態
  bill1~100.png   七種面額鈔票
  pill.png        適尿通藥盒
  life.png        補命代幣（爹地吐舌照圓形裁切）
  country-*.jpg   20 國服裝照
  voice/          20 國各三句當地話的男聲配音（mp3）
  win.mp4         三關全過的慶祝影片
```

## 常見修改

關卡難度全部集中在 `index.html` 的 `LEVELS` 陣列（第 393 行）：

| 參數 | 意義 |
|---|---|
| `time` | 關卡秒數 |
| `target` | 過關所需的實收面額（不含連擊、高空加成） |
| `pill` | 適尿通出現機率（0~1） |
| `spawn` | 掉落物生成間隔（毫秒，越小越密） |
| `bossMove` | 爹地移動間隔（毫秒，越小越跳） |
| `speedBase` | 基礎落下速度 |
| `drift` | 斜線幅度，0 為垂直 |
| `speedMul` | 速度倍率 |
| `junk` | 是否出現小面額干擾鈔 |

`WIN_AFTER_LEVEL` 控制第幾關過關後播放影片，測試時可改成 `0`（第一關就播）。

## 操作

- 電腦：滑鼠移動、方向鍵或 WASD，錢包可上下左右移動
- 手機：手指拖曳，錢包會停在手指上方一點，不會被手指遮住
- 垂直範圍限制在畫面下半部再往上一點（`BASKET_MIN_Y` ~ `BASKET_MAX_Y`），不能蹲在爹地正下方
- 任何模式進行中都能按右上角「🏠 主畫面」或 Esc 中斷回主畫面（不記分）

**特產**：每國一個 emoji 特產（`souvenir`），出差每關 8 到 20 秒間必掉一次，掉得慢、有光暈；接到 +$300 並存進 `wyd_souvenirs`，護照格子右上角顯示。集滿 20 國解鎖成就。

**當地話**：每國三句（`lines.intro/clear/fail`，原文加中文），出現在關卡介紹、過關、失敗畫面與護照點選。每句都預先合成一律男聲的 mp3 放在 `assets/voice/<國碼>-<intro|clear|fail>.mp3`，遊戲直接播放這些檔案，不依賴系統語言包；檔案缺失才退回瀏覽器語音合成。受音效開關控制。音檔用 `edge-tts`（微軟語音服務）以各語言男聲離線產生，需要重做時安裝 `edge-tts` 後跑同一份腳本即可。

**開始頁**：三張模式卡片（三關挑戰、世界出差、加班模式）各顯示說明與個人最佳；加班未解鎖時灰階並顯示解鎖條件。規則移到「❓ 怎麼玩」。

**音效 / 音樂分開開關**：左下角工具列兩顆按鈕，層級蓋過所有畫面，任何時候都能切。分別存 `wyd_sfx_muted`、`wyd_bgm_muted`。故事三關與加班模式也有背景音樂（`MUSIC.story` / `MUSIC.endless`）。

**各國背景音樂**：出差關卡進行中會循環播放該國風格的短旋律，由 Web Audio 現場合成（`MUSIC` 物件，每國一段 `melody` 與 `bass`，音量 `MUSIC_VOL`），關卡結束即停，跟音效共用左下角靜音。若要用真實音樂，在該國的 `MUSIC` 條目加 `track: 'assets/music/xx.mp3'` 就會改用音檔循環播放，請自備有授權的音樂。

護照有版本號 `PASSPORT_VERSION`，調高會在玩家下次載入時清空舊護照（擴充到 20 國時已做過一次）。

服裝圖 `assets/country-*.jpg` 由拼貼圖裁切，20 國全部使用，出現在關卡介紹、護照，以及出差進行中的遊戲背景（蓋一層淡暗色）；頂端發錢的爹地仍用九張髮量圖。

**過關門檻只算實收面額**：門檻比較的是本關接到的鈔票面額總和（`raw`，藥盒扣 50），不含連擊倍率與高空加成；含加成的小費（`score`）只用於累積總額與排行榜。時間到才結算，達標過關、未達標扣一命。

## 耐玩元素

- **高空加成**：錢包越高，接到的錢加成越多，最低點 ×1.0、最高點 ×1.5，飄字帶 ↑ 表示有吃到加成
- **加班模式（無盡）**：三關全過後解鎖。沒有目標、沒有時限，每 15 秒一波，藥盒機率、掉落速度、斜線幅度隨秒數爬升，直到藥盒過量倒下或按「下班結算」（Esc）主動結束。參數在 `endlessLv()`
- **排行榜**：故事、加班各存前五名於 localStorage（`wyd_board_story` / `wyd_board_endless`），上榜可留 4 字名字
- **成就**：12 個，定義在 `ACH` 陣列，解鎖狀態存 `wyd_ach`，開始畫面可查看
- **音效**：Web Audio 合成，無外部檔案，左下角可靜音（存 `wyd_muted`）

## 遊戲規則

- 接到 $10 / $50 / $100 加對應分數，乘上連擊倍率與高空加成
- 接到適尿通扣 50 分，爹地髮量 +1（分數可扣成負數）
- 接到 ✂️ 剪刀髮量 −1（道具中 70%）；🪒 刮鬍刀髮量 −2（30%，掉得更快）。道具不加分、不影響連擊
- 髮量整場累積，不因過關或重玩而重置
- **開局三命、上限五命**（`START_LIVES` / `MAX_LIVES`），三關共用，加班模式也用同一組
  - 沒達標：扣一命，該關分數歸零重來，髮量不還
  - 髮量 9/9 再接到適尿通：扣一命急救，髮量洗回 5/9（`RESCUE_HAIR`），該關重來；加班模式則原地繼續
  - 命歸零才真正結束
  - 「爹地人頭代幣」`assets/life.png`（由吐舌照裁切）每次生成 4%（`LIFE_CHANCE`），每關最多 3 個（`LIFE_PER_LEVEL`，加班模式每波重算）。代幣 76px、速度全場最慢（基礎速度的一半）；接到補一命，上限 5；命已滿時改給 $100（`LIFE_FULL_BONUS`）
